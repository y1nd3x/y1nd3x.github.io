How to Recovery WMIC on Windows

2026-09-14

Temporary mitigation guidance

This is a temporary mitigation intended to restore functionality for applications, scripts, or workflows that still depend on the WMIC utility. The downloadable WMIC package included in this mitigation is not a secure, long-term solution and should only be used at your discretion. We encourage you to move away from this workaround as soon as possible.

Steps:

  1. Download the wmic_dlc.zip file.

  2. Extract the contents of the ZIP file to a local folder.

  3. Open PowerShell as an administrator.

  4. Navigate to the extracted wmic_dlc folder.

  5. Run the following command: Set-ExecutionPolicy Bypass -Scope Process

  6. If you’re prompted to change the execution policy, select Yes.

  7. Run the following command: .\install.ps1

  8. Confirm that the script reports: WMIC has been installed successfully.

    • The installation script copies the WMIC files to the following directory and registers the required WMIC aliases: C:\Windows\System32\wbem.

    • Retest the affected application, script, or workflow.

  9. To verify that WMIC is working, run the following command: wmic
